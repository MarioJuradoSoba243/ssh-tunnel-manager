# Guía de usuario

La aplicación está en construcción incremental. La Fase 1 proporciona el shell inicial de JavaFX, con navegación vacía a Inicio, Túneles, Grupos, Hosts SSH, Organización y Ajustes.

El arranque actual no abre conexiones SSH ni restaura túneles. La persistencia, la configuración de hosts y túneles, y las operaciones SSH se incorporarán en fases posteriores.

La ventana inicial es de aproximadamente 1024×700 y la infraestructura de estilos incluye temas claro y oscuro. La selección persistente de tema y el seguimiento del tema de Windows aún no forman parte de esta fase.

> No describir funcionalidades como disponibles hasta que estén implementadas y verificadas.
