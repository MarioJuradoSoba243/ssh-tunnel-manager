# Guía de usuario

Esta guía se completará de forma incremental junto con la implementación.

> No describir funcionalidades como disponibles hasta que estén implementadas y verificadas.

## Estado actual

La aplicación dispone actualmente de un shell inicial en español con accesos a
`Inicio`, `Túneles`, `Grupos`, `Hosts SSH`, `Organización` y `Ajustes`. Estas secciones
son todavía marcadores vacíos: la gestión y las conexiones SSH no están implementadas
y no se inicia ninguna conexión al abrir la aplicación.
